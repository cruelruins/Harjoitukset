# Harjoitukset

Tämä repositorio sisältää opiskeluprojektien harjoituksia vuosilta 2025–2026.

Harjoituksissa on käytetty muun muassa seuraavia ohjelmointikieliä ja teknologioita:

HTML – verkkosivujen rakenne
CSS – ulkoasu ja tyylittely
JavaScript – interaktiivisuus ja toiminnallisuudet
Python – ohjelmointi ja erilaiset harjoitukset
PHP – palvelinpuolen ohjelmointi

Repositorio toimii kokoelmana opiskelun aikana tehdyistä harjoituksista ja projekteista sekä osoituksena ohjelmointitaitojen kehittymisestä vuosina 2025–2026.

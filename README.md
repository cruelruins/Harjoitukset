# Harjoitukset

Tämä sisältää opiskeluprojektien harjoituksia vuosilta 2025–2026.

JavaScript – interaktiivisuus ja toiminnallisuudet
Python – ohjelmointi ja erilaiset harjoitukset
PHP – palvelinpuolen ohjelmointi
